# Modern React + Vite To-Do App

A beautiful and responsive To-Do App built using React + Vite.

## Features

- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Completed
- Local Storage Persistence
- Filter Tasks
- Task Counter
- Empty State Message
- Responsive Design
- Smooth Animations
- Modern UI

---

## Installation

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

## Build Production

```bash
npm run build
```
